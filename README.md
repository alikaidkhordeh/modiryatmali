# 💰 مدیریت مالی — ربات تلگرام هزینه‌ها

یک ربات شخصی و **کاملاً رایگان**: هزینه را کوتاه می‌نویسی، ربات مبلغ و دسته (و شخص) را تشخیص می‌دهد و ذخیره می‌کند. آخر ماه گزارش، آمار، ویرایش و یک داشبورد با نمودار (مینی‌اپ تلگرام) داری.

```
بنزین ۵۰ تومن
قسط ماشین ۲ میلیون
شام با خانمم ۳۸۰
```

- عدد زیر ۱۰۰۰ یعنی هزار تومان (`۳۸۰` = ۳۸۰٬۰۰۰ تومان). «میلیون»، «هزار»، «ریال» و عدد با کاما هم فهمیده می‌شود.
- چند هزینه را می‌توانی در چند خط بفرستی.
- اگر دسته را نشناخت، دکمه‌های دسته را نشان می‌دهد. انتخاب تو را **یاد می‌گیرد** و دفعهٔ بعد خودش تشخیص می‌دهد.
- تاریخ و ماه‌ها شمسی است (ساعت تهران).
- هیچ هوش مصنوعی پولی لازم نیست (`ANTHROPIC_API_KEY` را خالی بگذار).

## نصب روی سرور (یک بار)

ربات در **پوشهٔ مخصوص خودش** نصب می‌شود (محیط پایتون، تنظیمات، دیتابیس و سرویس جدا) و به رباتای دیگرت دست نمی‌زند.

### ۰) آماده‌سازی
1. توی تلگرام با **@BotFather** گفتگو کن: `/newbot` ← اسم و یوزرنیم بده ← **توکن** را نگه دار (جایی عمومی نفرست).
2. به **@userinfobot** پیام بده تا **شناسهٔ عددی** خودت را بدهد.

### ۱) دانلود کد (با Termius به سرور وصل شو)
```bash
sudo apt update && sudo apt install -y git python3-venv
mkdir -p ~/bots && cd ~/bots
git clone https://github.com/alikaidkhordeh/modiryatmali.git
cd modiryatmali
```
> اگر ریپو **Private** است، clone با آدرس بالا رمز می‌خواهد. راه ساده: روی سرور `ssh-keygen -t ed25519` بزن (همه‌جا Enter)، محتوای `cat ~/.ssh/id_ed25519.pub` را در گیت‌هاب بخش **Settings ← Deploy keys ← Add deploy key** بگذار و با این آدرس clone کن:
> `git clone git@github.com:alikaidkhordeh/modiryatmali.git`

### ۲) نصب و تنظیم
```bash
bash deploy/setup.sh
nano .env
```
در `.env` این‌ها را پر کن (ذخیره: `Ctrl+O` ، Enter ، خروج: `Ctrl+X`):
```
BOT_TOKEN=توکنی که از BotFather گرفتی
ALLOWED_USER_IDS=شناسه عددی خودت
```
بقیه را دست نزن. (`WEBAPP_URL` در بخش «داشبورد» پایین توضیح داده شده.)

### ۳) آزمایش سریع
```bash
venv/bin/python -m bot.main
```
به رباتت `/start` بزن و یک هزینه بفرست. اگر درست بود با `Ctrl+C` ببند و مرحلهٔ بعد.

### ۴) اجرا به‌صورت سرویس (همیشه روشن، بعد از ریبوت هم)
```bash
bash deploy/install_service.sh
```

## 🎛 دستورهای روشن / خاموش (روی سرور)

| کار | دستور |
|---|---|
| وضعیت | `sudo systemctl status modiryatmali` |
| خاموش | `sudo systemctl stop modiryatmali` |
| روشن | `sudo systemctl start modiryatmali` |
| ریستارت | `sudo systemctl restart modiryatmali` |
| لاگ زنده | `sudo journalctl -u modiryatmali -f` |
| ۵۰ خط آخر لاگ | `sudo journalctl -u modiryatmali -n 50 --no-pager` |
| با ریبوت روشن نشود | `sudo systemctl disable modiryatmali` |
| با ریبوت روشن شود | `sudo systemctl enable modiryatmali` |

## 🔄 آپدیت
هر وقت کد جدید روی گیت‌هاب آمد:
```bash
cd ~/bots/modiryatmali
bash deploy/update.sh
```
(کد را می‌گیرد و ربات را ریستارت می‌کند؛ `.env` و دیتابیس سالم می‌مانند.)

## 💾 بکاپ
همهٔ داده‌ها یک فایل است: `data/expenses.db`. گاهی کپی بگیر:
```bash
cp ~/bots/modiryatmali/data/expenses.db ~/expenses-backup-$(date +%F).db
```
یا در ربات `/export` بزن تا فایل CSV (باز شدن در اکسل) برایت بیاید.

## 📊 داشبورد (مینی‌اپ تلگرام) — رایگان و بدون دامنه

صفحهٔ نمودارها فایل `docs/index.html` است که با **GitHub Pages** رایگان میزبانی می‌شود. ربات خلاصهٔ ماه را داخل خود لینک می‌گذارد، پس سرور، دامنه و تونل نمی‌خواهد.

1. گیت‌هاب ← ریپو ← **Settings ← Pages**
2. **Source: Deploy from a branch** ← Branch: `main` و پوشهٔ **`/docs`** ← Save
3. بعد از چند دقیقه صفحه روی `https://alikaidkhordeh.github.io/modiryatmali/` باز می‌شود (بدون پارامتر، داده‌های **نمونه** را نشان می‌دهد).
4. در `.env` همین آدرس را جلوی `WEBAPP_URL=` بگذار (در `.env.example` از قبل هست) و ربات را ریستارت کن.
5. در ربات `/app` یا `/month` بزن و دکمهٔ **📊 داشبورد با نمودار** را بزن.

نکته‌ها:
- حساب رایگان گیت‌هاب برای Pages ریپوی **Public** می‌خواهد. در ریپو هیچ رمزی نیست (`.env` و دیتابیس در `.gitignore` هستند)، پس Public کردنش مشکلی ندارد. اگر نمی‌خواهی Public باشد، یک ریپوی Public جدا فقط برای `docs/index.html` بساز و آدرسش را در `WEBAPP_URL` بگذار.
- خلاصهٔ ماه (جمع هر دسته، مجموع روزانه و چند هزینهٔ بزرگ) داخل لینک می‌رود، نه کل دیتابیس. شخص دیگری لینک را نمی‌بیند مگر برایش بفرستی.

## 🧭 کار با ربات

ربات منوی دکمه‌ای دارد؛ لازم نیست دستوری حفظ کنی.

| دکمه | کار |
|---|---|
| 📊 گزارش ماه | جمع کل، سهم هر دسته **به ترتیب بیشترین مصرف**، افراد، بزرگ‌ترین هزینه‌ها. دکمه‌های ماه قبل/بعد، بزرگ‌ترین‌ها و افراد زیرش هست |
| 📅 امروز | هزینه‌های امروز |
| 📈 داشبورد | مینی‌اپ نمودار |
| 👤 افراد | جمع هزینه‌ها به تفکیک افراد (خانمم، مامان، …) |
| 🕘 آخرین‌ها | ۵ هزینهٔ آخر با دکمهٔ 🏷 دسته · ✏️ مبلغ · 🗑 حذف |
| ⚙️ بیشتر | 🏷 مدیریت دسته‌ها · 📤 خروجی اکسل · ↩️ حذف آخرین هزینه · 💡 راهنما |

### 🏷 مدیریت دسته‌ها
از ⚙️ بیشتر ← 🏷 دسته‌ها:
- **اضافه کردن:** ➕ دستهٔ جدید، بعد اسم را بفرست. اگر اول اسم ایموجی بگذاری همان آیکون دسته می‌شود (مثلاً `🎮 بازی`).
- **ویرایش:** روی دسته بزن ← ✏️ ویرایش نام و ایموجی. هزینه‌های قبلی و کلمه‌هایی که ربات یاد گرفته با نام جدید می‌آیند.
- **حذف:** روی دسته بزن ← 🗑 حذف ← تأیید. هزینه‌های آن دسته به «سایر» می‌روند. دستهٔ «سایر» حذف نمی‌شود (جای هزینه‌های بی‌دسته است).
- هنگام ثبت هزینه هم می‌توانی با 🏷 دسته ← ➕ دستهٔ جدید، همان لحظه دسته بسازی و به هزینه بدهی.

### دستورهای تایپی (اختیاری)
هنوز کار می‌کنند ولی در منو دیده نمی‌شوند: `/today` `/month` `/lastmonth` `/top` `/person خانمم` `/app` `/last` `/undo` `/export` `/cats`، و `/addword کافی‌نت آموزش` برای یاد دادن دستی یک کلمه، `/addperson سارا سارا` برای تعریف اسم شخص.

آخرین روز هر ماه ساعت ۲۱ گزارش ماه خودکار برایت می‌آید.

شخص‌ها: «خانمم، همسرم، نامزدم، مامان، بابا، داداشم، خواهرم…» از قبل تعریف شده‌اند. اگر می‌خواهی «خانمم» و «نامزدم» در گزارش یکی شوند: `/addperson خانمم نامزدم`

## 🛠 عیب‌یابی
- **ربات جواب نمی‌دهد:** `sudo systemctl status modiryatmali` و `sudo journalctl -u modiryatmali -n 50 --no-pager`.
- **ربات می‌گوید «این ربات خصوصی است»:** شناسهٔ عددی‌ای که نشان می‌دهد را در `.env` جلوی `ALLOWED_USER_IDS` بگذار و ریستارت کن.
- **مینی‌اپ ارور ۴۰۴ می‌دهد («There isn't a GitHub Pages site here»):** GitHub Pages روشن نیست. ریپو باید Public باشد و در Settings ← Pages شاخهٔ `main` و پوشهٔ `/docs` انتخاب شده باشد. چند دقیقه بعد از Save آدرس بالای همان صفحه فعال می‌شود.
- **دکمهٔ داشبورد نیست:** `WEBAPP_URL` در `.env` خالی است. بعد از تغییر `.env` ریستارت لازم است.
- **`python3 -m venv` خطا داد:** `sudo apt install -y python3-venv`. نسخهٔ پایتون باید ۳٫۹ یا بالاتر باشد (`python3 --version`).
